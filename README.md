# Human Transcriptomic Meta-Analysis (`Human-Meta-Analysis`)

This repository contains bioinformatics workflows and script directories focused on human transcriptomic meta-analysis, stratified by sex and disease progression stages (Steatosis, MASH, MASL to MASH Progression, and Fibrosis).

## Directory Structure

The repository is organized by clinical phenotype and stratified by sex:

```text
├── Female Fibrosis/     # Meta-analysis and differential expression for female fibrosis
├── Female MASH/         # Meta-analysis for female metabolic dysfunction-associated steatohepatitis
├── Female Progression/  # Disease progression models in female cohorts
├── Female steatosis/    # Hepatic steatosis analysis in female cohorts
├── Male Fibrosis/       # Meta-analysis and differential expression for male fibrosis
├── Male MASH/           # Meta-analysis for male MASH cohorts
├── Male Progression/    # Disease progression models in male cohorts
└── Male Steatosis/      # Hepatic steatosis analysis in male cohorts
